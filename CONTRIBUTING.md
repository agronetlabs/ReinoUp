# Como participar

Sugestões e relatos de falhas são bem-vindos nas issues deste repositório.

Para relatar uma falha, informe:
- Tela ou atividade.
- Passos para reproduzir.
- Resultado esperado e resultado observado.
- Dispositivo e plataforma: web, PWA ou Android.
- Versão do aplicativo, quando disponível.

Para sugerir uma melhoria, explique a dificuldade e como a proposta ajudaria a criança ou o responsável.

As issues são públicas. Não publique dados de crianças, credenciais, informações de conta ou capturas que identifiquem outras pessoas. Este espaço não recebe o código-fonte privado do aplicativo.

Agradecemos comentários respeitosos e específicos. Não há prazo de resposta garantido.
